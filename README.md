# 📐 System Design Study

시스템 설계 스터디

## RADIO

**[RADIO](https://github.com/wooiljeong/RADIO)** 는 UI 컴포넌트 설계를 위한 경량 문서 포맷입니다.

- **R**equirements — 기능/비기능 요구사항
- **A**rchitecture — 디렉토리 구조, 유즈케이스, 설계 원칙
- **D**ata model — 타입 인터페이스, 필드 정의
- **I**nterface — 공개 API, 사용 패턴
- **O**ptimization — 렌더링 최적화 전략
